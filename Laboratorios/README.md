## 📁 Carpeta `laboratorios` (Archivos Funcionales y Copias de Seguridad)

Dentro de la carpeta **`laboratorios`** se alojan todos los archivos fuente utilizados y desarrollados a lo largo de las prácticas. Esta carpeta es fundamental, ya que sirve como una **copia de seguridad garantizada con versiones ya funcionales** de todo el proyecto. 

Aquí podrás encontrar:
* **Archivos Verilog (`.v`):** La descripción de hardware de todos los módulos (ALU, Unidad de Control, CPU completa, Memorias SRAM/ROM).
* **Testbenches (`_tb.v`):** Los entornos de prueba listos para ejecutar las simulaciones de cada componente.
* **Archivos Make (`Makefile`):** Para automatizar los procesos de compilación, simulación y limpieza del entorno de trabajo de forma rápida.
* **Programas en Ensamblador (`.s` y `.hex`):** Códigos de prueba compilados y listos para ser leídos por la memoria de instrucciones.

*Nota: Si durante tu propio desarrollo te encuentras con errores difíciles de depurar, puedes usar los archivos de esta carpeta como referencia directa, sabiendo que son versiones estables y probadas con éxito.*
